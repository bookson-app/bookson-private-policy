Bookson Privacy Policy

Effective Date: May 5, 2026
Last Updated: May 5, 2026

Bookson is a Chrome extension for organizing, searching, and managing Chrome bookmarks. It is intended for personal use and does not require account registration or the input of personal information.

Information Stored by Bookson

Bookson may store the following information in the user's browser or through Chrome's sync feature in order to provide its functions:

  • Bookmark URLs, titles, and folder information
  • Tags, notes, and favorite information added by the user
  • Stock and Read Later information
  • Extension settings
  • URLs, titles, and favicons of pages saved by the user through their own actions

Purpose of Use

Bookson uses the stored information for the following purposes:

  • Displaying, searching, organizing, moving, and deleting bookmarks
  • Managing tags, notes, and favorites
  • Providing Stock and Read Later features
  • Detecting duplicate URLs
  • Saving user settings
  • Exporting data based on user actions

Bookson does not use user data for any purpose other than those described above.

Data Storage

Bookson data is stored in the user's browser or synced between the user's own Chrome environments through Chrome's sync feature.

The developer of Bookson does not collect or store users' bookmarks, tags, notes, favorites, Stock data, or Read Later data on an external server.

Data Sharing and Transmission

Bookson does not send user data to the developer's server or to any third-party server.

Bookson does not sell, share, or transfer user data to third parties.

However, if Chrome's sync feature is enabled, data may be synced between Chrome browsers signed in with the same Google Account through Google Chrome's functionality.

Advertising and Credit Use

Bookson does not use user data for advertising, personalized advertising, retargeting advertising, credit evaluation, or lending purposes.

Permissions

Bookson uses the necessary Chrome extension permissions to provide features such as bookmark management, data storage, right-click menu actions, and file export.

These permissions are used only to the extent necessary to provide Bookson's features.

Data Deletion

Data stored by Bookson can be deleted through the extension's features, Chrome's extension management page, or Chrome's sync and storage settings.

Uninstalling Bookson may delete extension data stored in the browser.

Changes to This Privacy Policy

This Privacy Policy may be updated as necessary due to changes in Bookson's features, laws, regulations, or related policies.

Bookson プライバシーポリシー

制定日：2026年5月5日

Bookson は、Chrome のブックマークを整理・検索・管理するための Chrome 拡張機能です。個人利用を目的としたアプリであり、アカウント登録や個人情報の入力は必要ありません。

収集・保存する情報

Bookson は、機能を提供するために、以下の情報をブラウザ内または Chrome の同期機能に保存する場合があります。

  • ブックマークの URL、タイトル、フォルダ情報
  • ユーザーが追加したタグ、メモ、お気に入り情報
  • ストック、あとで読む情報
  • 拡張機能の設定情報
  • ユーザー操作により保存対象となったページの URL、タイトル、ファビコン

利用目的

Bookson は、保存した情報を以下の目的で使用します。

  • ブックマークの表示、検索、整理、移動、削除
  • タグ、メモ、お気に入りの管理
  • ストック、あとで読む機能の提供
  • 重複 URL の検出
  • 設定情報の保存
  • ユーザー操作によるデータのエクスポート

Bookson は、これらの目的以外でユーザーデータを使用しません。

データの保存場所

Bookson のデータは、ユーザーのブラウザ内、または Chrome の同期機能を通じてユーザー自身の Chrome 環境間で保存・同期されます。

Bookson の開発者は、ユーザーのブックマーク、タグ、メモ、お気に入り、ストック、あとで読む情報を外部サーバーで収集・保存しません。

データの共有・送信

Bookson は、ユーザーデータを開発者または第三者のサーバーへ送信しません。

また、ユーザーデータを第三者に販売、共有、転送しません。

ただし、Chrome の同期機能を利用している場合、データは Google Chrome の機能により、同じ Google アカウントでログインしている Chrome ブラウザ間で同期される場合があります。

広告・信用判断への利用

Bookson は、ユーザーデータを広告、パーソナライズ広告、リターゲティング広告、信用判断、融資目的には使用しません。

権限について

Bookson は、ブックマークの管理、データ保存、右クリックメニュー、ファイル保存などの機能を提供するために、必要な Chrome 拡張機能の権限を使用します。

これらの権限は、Bookson の機能提供に必要な範囲でのみ使用します。

データの削除

Bookson に保存されたデータは、拡張機能の機能、Chrome の拡張機能管理画面、または Chrome の同期・ストレージ設定から削除できます。

Bookson をアンインストールすることで、ブラウザ内に保存された拡張機能データが削除される場合があります。

プライバシーポリシーの変更

本プライバシーポリシーは、Bookson の機能変更、法令・ポリシー変更、または必要に応じて更新されることがあります。

Política de Privacidad de Bookson

Fecha de entrada en vigor: 5 de mayo de 2026
Última actualización: 5 de mayo de 2026

Bookson es una extensión de Chrome para organizar, buscar y gestionar los marcadores de Chrome. Está pensada para uso personal y no requiere registro de cuenta ni la introducción de información personal.

Información almacenada por Bookson

Bookson puede almacenar la siguiente información en el navegador del usuario o mediante la función de sincronización de Chrome para proporcionar sus funciones:

  • URL, títulos e información de carpetas de los marcadores
  • Etiquetas, notas e información de favoritos añadidas por el usuario
  • Información de Stock y Leer más tarde
  • Configuración de la extensión
  • URL, títulos y favicons de las páginas guardadas por el usuario mediante sus propias acciones

Finalidad de uso

Bookson utiliza la información almacenada para los siguientes fines:

  • Mostrar, buscar, organizar, mover y eliminar marcadores
  • Gestionar etiquetas, notas y favoritos
  • Proporcionar las funciones Stock y Leer más tarde
  • Detectar URL duplicadas
  • Guardar la configuración del usuario
  • Exportar datos mediante acciones realizadas por el usuario

Bookson no utiliza los datos del usuario para ningún otro fin distinto de los descritos anteriormente.

Almacenamiento de datos

Los datos de Bookson se almacenan en el navegador del usuario o se sincronizan entre los entornos de Chrome del propio usuario mediante la función de sincronización de Chrome.

El desarrollador de Bookson no recopila ni almacena los marcadores, etiquetas, notas, favoritos, datos de Stock o datos de Leer más tarde de los usuarios en un servidor externo.

Compartición y transmisión de datos

Bookson no envía datos del usuario al servidor del desarrollador ni a ningún servidor de terceros.

Bookson no vende, comparte ni transfiere datos del usuario a terceros.

Sin embargo, si la función de sincronización de Chrome está habilitada, los datos pueden sincronizarse entre navegadores Chrome en los que se haya iniciado sesión con la misma cuenta de Google, mediante la funcionalidad de Google Chrome.

Publicidad y uso crediticio

Bookson no utiliza los datos del usuario para publicidad, publicidad personalizada, retargeting publicitario, evaluación crediticia ni fines de préstamo.

Permisos

Bookson utiliza los permisos necesarios de las extensiones de Chrome para proporcionar funciones como la gestión de marcadores, el almacenamiento de datos, acciones desde el menú contextual y la exportación de archivos.

Estos permisos se utilizan únicamente en la medida necesaria para proporcionar las funciones de Bookson.

Eliminación de datos

Los datos almacenados por Bookson pueden eliminarse mediante las funciones de la extensión, la página de gestión de extensiones de Chrome o la configuración de sincronización y almacenamiento de Chrome.

Al desinstalar Bookson, es posible que se eliminen los datos de la extensión almacenados en el navegador.

Cambios en esta Política de Privacidad

Esta Política de Privacidad puede actualizarse cuando sea necesario debido a cambios en las funciones de Bookson, leyes, regulaciones o políticas relacionadas.
